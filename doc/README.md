# University Course Selection documentation

This folder contains the concise usage and architecture guide required for the Database Systems Project 2 course-selection application.

- `USAGE_GUIDE.md` explains the database model, constraints, test accounts, and launch steps.
- The project source is under `../src/`.
- The launch scripts are under `../run/`.

The assignment specification does not require a separate formal report. The usage guide is the documentation deliverable; screenshots may be added later only if the instructor requests them.
